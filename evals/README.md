# Model generation evaluations

此目录用于验证目标模型生成 OLL Authoring Profile 的能力。

评测必须分开报告：

- 协议质量：解析、Schema、语义引用和完整性；
- 教学质量：学科正确性、渐进性、讲述板书一致性和个性化依据。

第一次实验保留模型原始输出，不自动修复，以免掩盖 Authoring Profile 的真实难度。
