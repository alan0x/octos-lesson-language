# Geometry auxiliary line V2

这是一份以 `TEACHING-PLAYBACK-ACCEPTANCE.md` 为门禁手写的教学可理解性样板，不是模型生成样本。

它刻意与 V1 并存：V1 保留图片识别、资源 region 和首轮语言实验；V2 只验证学生能否跟随“已知 → 连接 AD → 三组边 → SSS → 两个结论”。

V2 使用现有 OLL v0.1，没有新增语法。它依赖 Reference Runtime 正确实现 diagram fragment emphasis、diagram-internal connection、table revise 和 board focus。

课程共有 11 个 Beat。垂线结论刻意拆为“对应角相等 → 平角推出两个 90° → 翻译为垂直”三步；自动断言和浏览器逐 Beat 结果见 `ACCEPTANCE.md`。
