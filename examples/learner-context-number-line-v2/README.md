# Learner-context adaptation V2

This is the fifth Phase 0 handwritten lesson. It demonstrates that learner
context changes the teaching strategy without writing a learner judgment back
into OLL:

- a visual number-line model appears before the symbolic conclusion;
- each Beat introduces one movement or conclusion;
- the reusable method is compressed into three short steps;
- `lesson.adaptation.context_refs` names the authorized evidence used.

The lesson does not claim that the learner mastered the concept and does not
emit a learner-profile mutation.
