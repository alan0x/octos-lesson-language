# 0011：接着写的卡片

状态：Accepted
日期：2026-11-06（用户确认的下一阶段：“growing card”，2026-11-05；表现力计划 A1）

## 背景

孩子讲解题过程时，会在上一张卡片的式子下面接着写：先写 `3x + 5 = 20`，下一张卡片在它下面写 `−5` 和 `3x = 15`，再下一张写 `x = 5`。现在每张卡片的笔迹都成为一张固定 340×230 的新卡片，由排版放进新的列；写在式子下面的步骤被缩小、搬走，解题过程散在白板各处，“=”也不再对齐。

## 决定

- 新的放置关系 `continues`：笔迹或数学卡片接着写在一张已有卡片上，`offset: {"x", "y"}` 记录它离锚点左上角的距离（白板单位，即孩子写下的位置）。只允许在 `learner_taught` 课程中使用，只允许笔迹和数学。
- 一张卡片和接着它写的所有卡片（可以一串接一串）组成一个整体：整体作为一张卡片参与排版，里面的卡片按 offset 摆放；Runtime 给整体画一个外框，里面的卡片不再各自画框。
- 接着写的数学卡片，以及替换接着写的笔迹的数学卡片（“整理一下”），可以 `align: "equals"`：Runtime 测量每张数学卡片中第一个“=”的位置，横向移动这张卡片，使它的“=”与整体中上面最近一行数学的“=”对齐。
- 笔迹新增 `drawn_size: {"width", "height"}`：按写下时的大小显示，超过 1200 宽时等比缩小；没有 `drawn_size` 的旧笔迹保持原样。
- 锚点被隐藏时（擦掉、整理成数学），接着写的卡片接到替换它的卡片上；没有替换时接到它所接的卡片上并累加 offset；它本身就是整体第一张时，下一张占用它在白板上的位置。
- 能力 `placement:continues` 与 `ink:drawn-size`，执行版本 0.9.0。

## 原因

“写在哪里”是孩子讲解的一部分。用相对锚点的 offset 而不是白板坐标，整体仍由排版放置，不会与其他卡片重叠，也不需要模型或宿主输出绝对坐标；“=”对齐由 Runtime 根据实际渲染测量，作者不写像素。

## 后果

- Core：Schema、校验（offset 必填且只属于 `continues`，`align: "equals"` 只属于数学的 `continues`）、执行能力。
- Web Runtime：`computeBoardLayout` 把整体当作一张卡片排版并返回 `blocks`；`visibleBoard` 处理被隐藏的锚点；Board View 测量“=”、画整体外框、按 `drawn_size` 显示笔迹。
- Octos Learn 录课工作室：写在已有笔迹或数学卡片上或其下方的笔迹接着写在那张卡片上；整理这样的笔迹得到的数学接着写在同一位置并对齐“=”。
