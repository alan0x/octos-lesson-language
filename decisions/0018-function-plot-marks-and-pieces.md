## 决定

### 1. 标记：一个节级选项，模型只点名，程序推出、绑定、检查

一个选项 `marks`，列出要画的标记。标记不改变数的含义，所以是选项，不是新配方（0016 的规则只约束数的含义）。

| 标记 | 模型写 | 程序推出并画出 | 滑杆拖动时 | 卡片 |
|---|---|---|---|---|
| 截距 | `intercepts` | 线性和二次函数：用公式写出交点坐标表达式，画点；标签只写“y 截距”“x 截距”，不写数值 | 点跟着走 | 已有 |
| 顶点 / 对称轴 | `vertex`、`symmetry_axis` | 二次函数：顶点表达式和过顶点的竖线；标签写“顶点”“对称轴” | 点和竖线跟着走 | 已有 |
| 斜率三角形 | `slope_triangle` | 用函数图已有的两个采样点画“前进 Δx、上升 Δy”两条线段 | 线段端点跟着采样点走 | **要新增**：可绑定端点的线段 |

- **表达式写不出来时**（不是线性或二次函数）不提供这个标记，在节里拒绝，让节换一个画法（问题 2）。
- **拖动中标记会消失**：例如抛物线抬离 x 轴，横截距不存在。卡片要在这一刻隐藏这个点，而不是画到窗口外或画错（渲染检查的一项）。
- **洞**：视图规划已经自动处理，不在这次范围。

### 2. 分段函数：每段一个公式和区间

| 配方 | 模型写 | 程序推出并画出 | 卡片 |
|---|---|---|---|
| 函数图（已有）加 `pieces` | 每段：公式、区间（左右端点）、端点开闭 | 每段只在区间上画；端点按开闭画空心或实心；检查各段区间不重叠 | **要新增**：区间曲线、端点开闭 |

- **常数段**（`2`）在分段时允许：它只在区间上画，不会被当作整条横线。
- 不分段的函数图仍然拒绝常数公式，规则不变。

### 3. 定义域 / 值域：坐标轴上的区间，只用精确公式

`marks` 再加两个值 `domain`、`range`。横轴上画定义域，纵轴上画值域，画法和数轴的区间一样：粗线段；端点取到画实心，取不到画空心；没有端点画箭头；去掉一个点（如 x ≠ 0）画成两段，空心端相对。

**只用精确公式，不用采样估计。** 采样分不清“取到 0”和“无限接近 0”，而把取不到的端点画成实心正是误导。所以程序只对下面的函数族写出区间，其他一律在节里拒绝（同问题 2）：

| 函数族 | 定义域 | 值域 |
|---|---|---|
| 直线 mx + c | 全体实数 | 全体实数；m = 0 时只有 c |
| 二次 a(x−h)²+k | 全体实数 | a > 0：[k, +∞)；a < 0：(−∞, k] |
| 根式 a√(x−h)+k | [h, +∞) | a > 0：[k, +∞)；a < 0：(−∞, k] |
| 反比例 a/(x−h)+k | x ≠ h | y ≠ k |
| 指数 a·bˣ + k、对数 a·log(x−h) + k | 全体实数 / (h, +∞) | a > 0 时 (k, +∞)，a < 0 时 (−∞, k) / 全体实数 |
| 分段 | 各段区间，取模型写的端点和开闭 | 逐段求值域再合并 |

- **端点跟着滑杆动**：每个端点是滑杆的表达式，开闭由函数族决定，拖动时不变。
- **跨过退化点**：例如二次的 a 拖过 0，值域方向翻转；a = 0 那一刻曲线变成直线，值域按直线画。这是渲染检查的一项。
- **端点在窗口外**时画箭头到窗口边，不画到窗口外。

### 4. 先渲染，再判定器，再配方（计划 §5）

1. 本仓库先加三样渲染：可绑定端点的线段；区间曲线和端点开闭；坐标轴上的区间（复用数轴的画法）。再加一项行为：标记不存在时隐藏。都在真实播放器里检查。
2. **判定器**：函数图今天没有（问题 3）。
   - 和数轴判定器一样，每道用例预先写好期望的值（截距坐标、三角形的 Δx 和 Δy、各段端点、定义域和值域的端点与开闭）。不拿程序自己推出的值去比，否则判定器只是在检查自己。
   - 加反例（画错必须判不通过）。
3. 再写选项和推导。先用真实生成流程测试，再做小试验：对照组和候选组，同样的新用例，每组重复两次。调用次数在试验前报给产品负责人。
4. 与 0017 一起冻结代码，与 Coach #81 一起做一次速度检查（三组，用 `--previous-build` 区分影响）。

## 实现前核实（2026-11-14，渲染检查之前读代码和播放器得到）

与上文和产品负责人确认时的说法不同的地方：

1. **斜率三角形不需要新的线段。** 函数图的 `measurement: "secant"` 加两个采样点，今天已经画出割线、Δx 和 Δy 两条虚线腿，并在图下实时显示“Δx = 1 · Δy = 2 · 割线斜率 ≈ 2”。Coach 在标题或目标含“斜率 / 割线 / slope / secant”的单公式课里已经自动加上 A、B 两点（`math-compilers.ts`）。这两道题的课没有录过（不在 60 题基线里），所以今天是否触发没有核实：G68-26 用的词是 gradient，不在触发词里；G68-28 要看模型写的标题。`marks` 里的 `slope_triangle` 由程序直接加上 A、B，不再依赖措辞。
   - 要做的是润色：直线上读数写“斜率”而不是“割线斜率”；两条腿标上 Δx、Δy；三角形太小（Δx = 1）时放大。前两项在 OLL #62 的渲染器里做了（读数写“斜率”的条件是两点所在的那条曲线是直线，而不是第一条曲线）；放大不在渲染器里做，因为两点是课里写定的，渲染器不能挪动它们：由 Coach 的配方给 A、B 选足够的间距。读数写“斜率”要求两点所在的每条曲线都是直线（课里在抛物线前画了过 A、B 的直线时仍写“割线斜率”）。多于两个点的割线测量需要 `plot:secant-first-two`（0.11.0），因为 0.10 的播放器这时不画三角形。同一 `series` 的各段每个 x 至多覆盖一次，重叠的分段由 OLL 拒绝。
   - 原先“可绑定端点的线段”从渲染清单里去掉。
   - 割线原来只在恰好两个点时画，加上截距等标记点就不画了；改为测量前两个点（OLL #62）。Coach 把 A 放在 x = 0，正好落在 y 截距上，配方要避开。
2. **标签可以写实时数值。** 点的标签支持 `{x}`、`{y}`、`{coords}`，拖动时跟着更新。上文“标签是固定文字”只对普通文字成立。本决定仍然只写“顶点”“y 截距”这类名字；是否显示实时坐标留到试验后再定。
3. **“标记不存在时隐藏”今天只对点有效。**
   - 点：`hide_when_undefined` 已有，但初值时就不存在的标记（开始时抛物线在 x 轴上方，没有横截距）被 core 拒绝，要放开。
   - 竖线 / 横线（对称轴）：不能用这个标志，值不存在时课程报错。要新增，并且用新的特征名，因为旧播放器会把竖线画在旧位置上。
4. **新渲染需要播放器 0.11.0**：区间曲线、坐标轴上的区间、竖线的隐藏各一个特征名。旧播放器会忽略这些字段，把分段函数画成整条曲线，这就是误导，所以必须按特征名拒绝。
5. **分段函数用几条曲线、共用一个系列号来表示。** 每段是一条曲线，带自己的区间和端点开闭，几段写同一个 `series`，颜色、线型和图例按一个函数处理。探索模式今天按曲线序号给颜色和图例，要改成按 `series`。Coach 的“多式仅静态比较”规则不变，所以采样点不会跨过断点。
6. **值域方向翻转（a 拖过 0）**：用“标记不存在时隐藏”表示，不加新字段。两条区间各写一个只在 a > 0 或 a < 0 时有定义的端点表达式，另一条隐藏。
   - a = 0 那一刻曲线变平，两条都隐藏，单个值 {k} 不标。这是少画，不是画错。
   - 所有函数族同样处理：根式、反比例、指数在 a = 0 时都变成常数，值域条隐藏。直线 m = 0 时同样隐藏。
7. **分段函数的值域只做各段都是直线或常数的情况**（端点值和开闭可以精确合并，常数段是一个点）。含二次或其他段时只画定义域，值域在节里拒绝。
8. **纵轴上的区间是新代码**，数轴的画法只能借鉴。0 不在窗口里时没有坐标轴线，区间画在边框上。
