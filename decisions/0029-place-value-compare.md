## 背景

- 按 2026-11-21 的顺序，数位表（0025，35P-05）、在表上加减（0026，35P-07）之后，35P-06 是数位表上的另一个兄弟。

- 0025 的第一次客观检查里，近似题 PV-16（比较 0.625 和 0.7）借了数位表，因为没有组件服务这个需求。0025 的 PV-16、0026 的 PT-17（3.09 和 3.1）都是本需求的近似题。

- **第一次冷读**（2026-11-26，新的代理只看截图）：「=」「≠」加圈、斜线「不影响」都读得很清楚（A 3、B 3、C 4、D 3 分）。第二次冷读 A 3、B 4、C 3、D 2、E 4：改了按钮的字、题目的问法、决定那一位的事实、拒绝的样子和话、小数点和圆片上的小字。之后产品负责人试用，按建议改成每一列「一样」「不一样」两个按钮。两个严重的问题：按这一位的单位数一数的检查读不懂（多数孩子会输入 3 和 0，而不是 453 和 450）；决定以后事实行直接说出了谁大。都已改（见第 3、4 节）。

## 决定

### 1. 一个新卡片和一个配方，只服务 35P-06

- 数学插件新增卡片`place_value_compare`，Coach 新增同名配方，试用（默认不开）。
- **概念**：两个数按数位对齐，从最高位比起；第一个不一样的数位决定谁大，它后面的数位不影响。
- **用 0025 的数位表的积木**，但这是另一个卡片：一个需求一个组件。
- **不做的**：摆数、拆数（35P-05）；十个这一位是左边一位的一个（35P-04）；在表上加减（35P-07）；凑整、估算（35P-01）；乘除以 10 的幂（35P-11）；一、二年级比两位数、三位数（K2N-24）；四年级用百格图比小数（FR-16）；比分数（FR-07 到 FR-09）。

### 2. 画面：一张表，两行，按数位对齐

- 列是数位（列名、颜色、圆片、小数点同 0025）。只画需要的列：从两个数最高的一位（至少到个位）到两个数写出来的最低一位；最多七列（1,000,000 和 999,999；3,456.789 和 3,456.798）。
- 第一行是第一个数的圆片，第二行是第二个数的圆片；两行之间每一列两个按钮「一样」「不一样」（英文「Same」「Different」）。第一次冷读里「?」被读成「帮助」，第二次「=?」读不懂；产品负责人试用时，一个「一样吗？」在数字不同的列上让人困惑，建议改成两个按钮（2026-11-26）。
- **空的格子写一个淡淡的「0」**：0 和 0 一眼就是一样的（冷读里 C 的个位两个空格让人犹豫）。0.7 的百分位、千分位也是「0」，正好说明 0.7 = 0.700。
- 左边写着两个数，**照写法写**（0.7 不补成 0.700），**按小数点对齐**（整数按个位对齐）。所以画面本身不支持「按最后一位对齐」。
- 每一格最多九个圆片，三个一行；两行同一位置的圆片上下对应，配对一眼看得出。每一格一开始就留出这道题最多需要的地方，卡片不会长高。
- 第一屏：题目「比较 0.625 和 0.7。」（英文「Compare 0.625 and 0.7.」；不问「哪个大」，「=」也是可能的答案），**紧接在题目下面**一行说明「从左边起，一位一位判断，直到有一位不一样。」；小数点画大，一条点线从上到下穿过两行，表，表下面灰着、锁着的一句「0.625 [> = <] 0.7」，下面一个锁和一句事实「找到不一样的一位，或每一位都一样后才能选。」（同 35P-04 的锁的写法）（同 0026 一开始就灰着的「和：」，让孩子一开始就看到最后要做什么）。没有别的说明段落。
- 0.625 和 0.7 的第一屏上，0.625 有 13 个圆片，0.7 只有 7 个；圆片多的那个小，这正是要孩子看到的。

### 3. 孩子做什么（动作就是概念）

- **孩子判断每一位**：每一列点「一样」或「不一样」，从左边起一位一位来。表不替孩子比：第一屏和判断之前都不标出决定的那一位，也不替孩子标任何「=」。
- **对的判断才被接受**，每一次点都说一句真的事实，用普通颜色，在选符号以前都不说哪个数大；被拒绝的那个按钮晃一下，变成灰色虚线的样子，直到下一次点（悬停只让按钮浮起一点，不填色；载入时不让任何按钮获得焦点，免得看起来像已经选了）：
  - 「一样」点在一样的一列上：这一列标「=」（「千位：4 和 4，一样。」）。
  - 「一样」点在不一样的一列上：拒绝，只说这一列的两个数字（「十位：3 和 0。」）。冷读截图 F。
  - 「不一样」点在一样的一列上：拒绝，只说这一列的两个数字（「千位：4 和 4。」）。
  - 「不一样」点在第一个不一样的数位上：这一列标「≠」，加一圈蓝边；两行里能配成对的圆片淡下去，多出来的圆片亮着、带一圈；它右边的列盖上斜线，写着「不影响」。事实行：「十分位：6 和 7，第一位不同。0.7 的 0.1 多。」——说这一位谁多（圆片已经画出来了），不说哪个数大（第一次冷读：先说出谁大，孩子就不用自己下结论了；第二次冷读：要有一句话把这一位接到选符号上）。一行说明变成「在下面两个数中间选 >、= 或 <。」，下面那一句打开。
  - 任何一个按钮点在左边还有没判断的位的一列上：拒绝，说出最左边还没判断的那一位：「千分位：5 和 0。个位还没有比。」；这一列变暗（没有斜纹，斜纹是「不影响」的意思），按钮变淡，最左边还没判断的那一位轻轻标出来。不说是哪一位决定、也不说哪个数大。这正好碰上「从个位比起」「按最后一位比」的错误想法。4,530 和 4,630 在个位点「一样」（0 和 0）也是这样的一句（「个位：0 和 0。百位还没有比。」）；百位判断了以后，是「已经由百位决定了；个位在后面，不影响。」。
- **左边的列不自动标「=」**（主会话倾向自动标；这里建议不标）：一个按钮时，点一下是「这是第一个不一样的数位」的判断，左边自动标「=」说得通。两个按钮时，每一个「=」都应该是孩子自己说的「一样」；而且「左边还有位没有判断」的拒绝对两个按钮一视同仁，「不一样」点在决定的那一位但左边没判断时也说这一句，规则只有一条、句子总是真的。代价是多点几下「一样」，那正是「从最高位比起」这个动作本身。
- **选符号就是孩子的结论**：在「0.625 [> = <] 0.7」里点一个。对了，句子变成「0.625 < 0.7」，事实行才说完整的话：「✓ 0.625 < 0.7：由十分位决定，后面的数位不影响。」。不对时只说事实：「“0.625 > 0.7” is not true.」/「「0.625 > 0.7」不成立。」，三个按钮还在。
- **决定以后再点后面的一列**：「已经由十分位决定了；百分位在后面，不影响。」
- **两个数相等**（0.7 和 0.70；4.300 和 4.3）：每一位都点「一样」，最后一位以后事实行说「每一位都一样。」（不说「相等」），下面那一句打开，孩子选「=」。冷读截图 E 是这个状态。
- 「看我做一遍」从最高位起一位一位地点「一样」，在决定的那一位点「不一样」，每一位说一句，再点对的符号（「所以 4,530 > 4,503。十位后面的数位不影响。」）；然后「轮到你」换另一对数。
- 乱点不会把表弄坏：表的全部状态是一个整数（从左边起标了几列），只有正确的比较才会改变它；所有可能的状态都在测试里穷举过。

### 4. 检查（只读卡片的事实和孩子的输入）

- **检查有两步，都是孩子自己的**：先在表上找到第一个不一样的数位（状态：程序只接受这一位，右边的被拒绝）；然后选 >、= 或 <（程序判断）。符号只有在表上比完以后才能选，所以它是从表上得出的结论，不是在三个里猜。
- **和组件地图不一样的地方**：地图第 6 行写的是「每个数按这一位的单位数一数（453 个十和 450 个十）」，并说 >、=、< 是选择题，不作检查。冷读证明前者读不懂，还依赖 35P-04 的概念（十个这一位是左边一位的一个），这张卡片不画它；所以改成选符号（主会话 2026-11-26 按冷读决定）。代价：选符号有三分之一能猜对；但它只在孩子先在表上找对了那一位以后才打开，那一步不能猜。
- 卡片在孩子选对以前，不写出「谁大」和那一句对的式子。

### 5. 模型写什么，程序算什么（0020 的三个问题）

- **模型写**（四个课的数，都是老师自然会写的数）：
  - 要比的两个数（mantissa 和 scale，保留写出来的末尾的 0：0.70 是 70 和 2；不是负数；最多三位小数）；
  - 练习的两个数（另一对，不是演示的那对，正着反着都不行）。
- **不让模型声明从 0 开始的计数**：0026 的第一次客观检查里，「做完了几列」这个从 0 开始、没有明显教学作用的数在 20% 的提纲里被漏掉。这里「比到了第几位」由程序随两个数一起提供（同 0026 的修正）。演示的目标写在数据上：演示比到哪一位（位名，如「十分位」）；不写的时候比到决定的那一位，再选符号。一节课可以只演示一部分。
- **程序给后面几节的事实**：决定的是哪一位、两个数在这一位各是几、表上现在比到了哪一位、孩子选的符号对不对。
- **程序算**：列、圆片、配对、决定的那一位、后面的「不影响」、对的符号、读法。卡片读 mantissa 和 scale，不读四舍五入以后的小数。
- **会出问题的数不接受**（编译器拒绝，标上这个能力，只重写这一节或去掉这张图，课不丢）：超过七列；超过三位小数；两个数写得一模一样（没有可比的）；练习和演示是同一对。

## 草图里定下的细节

- **一个整数就是整张表的状态**：从左边起判断了几列（0 到决定的那一位）。只有下一列上对的判断会改变它。
- **事实和拒绝都只说事实，用普通颜色**；只有选对的那一句用绿色。
- **检查穷举**：两种语言列出的 17 道题所有能到的 65 个状态；2,000 对随机数里，「第一个不一样的数位」给出的大小关系和数值本身的大小关系每一次都一致；表比完以前不能选符号，比完以后只有对的符号被接受；演示总能走到决定的那一位；第一列以外的每一列，开始时两个按钮都被拒绝；决定的那一位上点「一样」被拒绝。
- **页面检查**（真点击）：每一道题两种做法（每一次都判断对；先犯各种错再判断对）、两种语言；第一屏每列「一样」「不一样」、灰着的一句、每个空格子都有「0」；先点右边（两个按钮都试）被拒绝、表不变、那一列是「还没轮到」的样子、最左边没判断的一位轻轻标出、普通颜色；判断错了只说那一列的两个数字；配对和多出来的圆片个数；「不影响」只在后面还有列时出现；选符号以前不说谁大、不写对的式子；选错说事实、按钮还在；选对以后再点表也不会盖掉结果；相等的一对点到最后才打开；演示选对符号；练习；1024 像素宽七列不横向滚动；圆片上的字不被截掉；说明在题目正下方、只有一行。

## 修订

- 2026-11-27，修订 1（OLL #128、#130 做出来的样子，和上文不同的地方）：
  1. **版本。** 播放器 0.20.0（`card:place_value_compare`），数学插件 0.12.0。演示的节奏（#129，数学插件 0.11.1）先合进去；本卡片的演示用它的 `stepValues`。
  2. **点按都是 `{kind, place}`，四种。** `same`、`different` 是一列下面的两个按钮，`place` 是数位加三（个位 3）；`sign` 的 `place` 是 10 到 12（>、=、<）；`column` 是比完以后点一列，总被拒绝，拒绝的话就是这一列的事实（「已经由十位决定了；个位在后面，不影响。」，草图里比完以后点一列的样子，#128 的审查要求留下）。不是第 7 节的 `compare` 加一个值。
  3. **每个数写出来的小数位数。** `a_decimals`、`b_decimals`（可选，0 到 3；不写就是数本身需要的位数），所以 0.7 和 0.70 是一对（C6）。
  4. **一个任务事实 `complete`**（孩子比完并选对了符号），用现有的 `student-tasks:card_fact:complete`，不是第 7 节的 `decided` 和 `signed`。卡片任务总从自己的一对数重新开始，所以「找到那一位」和「选符号」不能是同一对数上的两个任务。「比完了」仍是给后面几节的事实（`placeValueCompareFacts`）。演示到最后、符号已经画出来，也不算孩子完成（#128 的审查）。
  5. **选的符号是孩子的状态。** `signed`（0 或 1）和 `marked`（0 到 7）一样是绑定的变量：卡片的事实只读卡片的状态，选对的那一下必须改一个字段。所以第 7 节「选的符号不是变量」不成立。两个范围和是哪一对数无关。
  6. **演示 `compared` 一直到选符号。** 0 到决定的那一列加二：每一步判断一列，最后一步选对的符号；不能往回，不能超过最后一步。播放器一步一步地设，每一步一个演示的时间（0026 修订 2），卡片把这一步画在这段时间里：正在判断的那一列有一圈，「=」「≠」出现，圆片和下面对应的圆片一起跳一下；最后选的符号出现。
  7. **演示时卡片上不写演示的话**（第 3 节「每一位说一句」）。卡片上只有表的变化；每一步的话由课自己讲（`placeValueCompareStepSentences` 给后面几节用）。依据：产品负责人 2026-11-24「程序不写旁白」，同 0027、0028。演示时卡片上的说明行也是空的。
  8. **课的变量** 5 个（`a`、`b`、`compared`、`marked`、`signed`），绑定小数位数时 7 个。练习的两个数是练习任务的起点，不是课的变量（同 0026、0028）。
  9. **圆片大小** 按草图的样式（产品负责人试用的那一版）：四列以内 34 像素，五列 31，六列 30，七列 28（第 7 节写的是 34、31、28、26）。七列时 100,000 这样的字压窄放进圆片里。

      - OLL 只拒绝和课里完全一样的练习；反过来的一对（课 4530 和 4503，练习 4503 和 4530）OLL 接受。
      - 课是 0.7 和 0.70 时，练习如果是值一样、写法不一样的另一对，OLL 只比较值，会当成「课里自己的那一对」拒绝。
      - 一个数写了末尾的 0 时，Coach 要把两个小数位数都绑定，不然练习会沿用（0.5 画成 0.50）。
