# 0020：模型写意义，程序写逻辑

状态：Accepted（产品负责人 2026-11-16 批准，含 0018、0019 的修订提案）
日期：2026-11-16（数学表现力计划 §7 第 3 步；产品负责人 2026-11-16 提出两条原则，Fable 两次评审后整理）

## 背景

`sample_x_numbers` 要求模型写“大纲里第几个数”，模型常把它写成 x 坐标（`[1, 3]` 表示 x = 1 和 3）。录下的回复里一共 42 次。速度门里有两节课因此在四次调用后丢失。三次修复都在评审中被关掉：

1. **按 x 坐标就地修复（Coach #102）**：模型的公式有时是占位的（过 (1, 2) 和 (7, 10) 的直线写成 `x`），程序从文字判断公式真假不可靠。
2. **把这一项限制为有效序号（#105 第一版）**：有课中数时，模型想写的 x 值会被压成一个有效但错误的序号，点被悄悄绑到无关的滑块上。
3. **没有课中数时去掉这一项（#105 收窄版）**：那次拒绝原本顺带挡住了另一个错（分段函数画成两条整线，PJ-07），去掉以后它就发布出去了。

## 产品负责人的两条原则（2026-11-16）

1. 模型负责创造性、教学性和语义性的内容；需要严格逻辑的事交给确定性的程序。
2. 程序要承认模型的输出是随机、不可预测的，尽量容纳这种变化，同时保证最终结果正确。

## 决定（建议）

### 1. 判断一个字段该谁写：三个问题

1. **它是意义，还是别的字段的结果？** 能从其他字段加数学推出来的，模型就不该写。例子：标记的位置由程序算，模型只点名（0018）。
2. **模型是照抄或从枚举里选，还是要数、算、追踪？** 照抄它在旁白里也说的值是安全的；“别处某个列表的第几项”这种裸整数是在数数，最容易错。
3. **写错了，程序能不读文字就发现吗？** 每个错值要么写不出来，要么和另一个结构化字段对不上。例子：问答题的 `answer` 和 `check` 互相校验。

另加一条：**一个字段只有一个意思，模型可能想表达的每种意思都有地方写。** `sample_x_numbers` 违反了这条：名字里有 x，提示里叫它“A/B 横坐标”，类型却是裸整数。

### 2. 容纳模型的变化：一架梯子

核心规则：**文字可以触发拒绝，但不能决定画出来的值。** 误拒只多花一次调用；从文字猜出来的值可能误导。

遇到一个错，用第一级适用的办法：

1. **能写出来**：schema 给每种可能的意思一个位置，就没有可拒绝的。
2. **规范化**：只看结构化字段就只有一种读法时，直接采用，并记录下来。注意，“一种读法”要对模型的**本意**成立，不只是对写下的字段成立。反例：倒序的不等式端点，换个顺序看似只有一种读法，但模型也可能选错了关系，换完会画出旁白所说集合的补集（Coach #108 评审）。
3. **推出来**：程序能算的值，忽略模型写的。
4. **放弃**：只在没有旁白依赖它的时候，丢掉这一部分。可以放弃的例子：课后附加题、成功提示语；不能放弃的例子：旁白在讲的斜率三角形。
5. **换一种问法重试**：重试时收窄 schema，让刚被拒绝的错写不出来（要求缺的字段，去掉用错的字段）。收窄在这一节以后的每次尝试里都保留。
   - **限制**：只有结构化的事实才能决定怎样收窄，例如“这节课没有课中数”。**由文字触发的拒绝，重试必须是自由的**，不能因此要求或去掉某个字段。否则文字就决定了画什么。Coach #109 的分段函数检查就是这样出错的：它看到“当 x < 0 … 当 x > 2”就要求重试写 `pieces`，把两条曲线的比较画成了一个错误的分段函数；有滑块的公式、或者超过四段的函数，重试根本写不出来，课就丢了。
6. **拒绝**：只在意义出错时拒绝：错误的数学说法、读不懂的公式、对不上的校验值。

### 3. 程序不该做的事（陷阱）

- 从自由文字推断意图，再据此画东西（#102）。
- 程序替旁白里已经说出的值做选择（程序自己放斜率三角形的两点，而旁白讲的是它自己的两点）。
- 悄悄把错值压成合法值（#105 的枚举、#78 之前的 8 格夹紧）。
- 一个拒绝顺带承担另一个检查，去掉它时另一个错就漏出去了（PJ-07）。核对时要看被重放的回复是哪一种请求写的：PJ-07 的错画都出现在还没有提供 `pieces` 的请求里；在现在的请求下，录下的 25 节分段函数课都画了分段。
- 由文字触发的拒绝，配上要求或去掉字段的重试（#109）。

### 4. 留给模型的

选哪种画面、公式、每个数代表什么及其范围和初值、旁白、动画让哪个滑块走到哪个值、问题和答案、分段的分界点。

### 5. 怎样落地

- **一次只改一个字段。** 每次改动模型收到的请求，都要单独做配对探针，再过速度门（+0.5 s）。
- **第一个字段**：函数图的点，见 0018 的修订提案。
- **3D 立体**：见 0019 的修订提案。
- **以后的候选**，先免费统计再决定：
  - 画面上数的顺序（角度和半径对调是合法但错误的）；
  - 练习目标：由程序写邀请语（Coach #81）。
