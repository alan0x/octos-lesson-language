# 0009：结束强调

状态：Accepted
日期：2026-11-05（用户反馈：2026-11-05）

## 背景

`board.emphasize` 只能叠加强调，没有办法结束。孩子录课时在第 1 张卡片用荧光笔标出单位圆上的点 P，之后每张卡片 P 都一直是黄色；第 3 张讲余弦时，观看的人应该看 x 轴上的点，P 仍然最醒目。

## 决定

- `emphasis` 新增取值 `none`：结束同一目标此前的强调（目标为同一 node，或同一 fragment）。Reducer 照常记录这条强调，渲染取每个目标最后一条强调，因此 `none` 让它回到未强调的样子。
- `none` 不吸引注意：Runtime 不为它移动镜头。
- 能力 `emphasis:none` 的执行版本为 0.7.0；播放器执行版本升为 0.7.0。旧播放器会把未知取值当作 `focus`，所以必须用能力门禁拦住。
- 宿主从录制生成课程时，每张卡片开始先结束上一张卡片的荧光笔强调；强调只在标出它的那张卡片里有效。

## 原因

强调是“现在看这里”，属于某一段讲解；用取值而非新动作，保持动作集合不变，旧课程不受影响。

## 后果

- Core：执行能力与版本；Schema 与校验不变（`emphasis` 仍是字符串）。
- Web Runtime：`none` 不加强调样式、不移动镜头。
