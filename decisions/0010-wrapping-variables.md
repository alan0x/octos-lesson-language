# 0010：一整圈的变量

状态：Accepted
日期：2026-11-05（用户反馈：2026-11-05）

## 背景

单位圆的角度 θ 范围是 `[0, 2π]`。上一张卡片把 θ 转到 2π 后，点 P 回到起点，看起来和 0 一样；孩子从那里逆时针拖动 P，数值本应越过 2π 回到 0 附近，但变量不能超出 `max`，录下来的仍是 2π，松手后 P 跳回原处。`lesson.variable.animate` 也只会从当前值直线走到 `to`，从 6.27 到 0.95 会反方向转几乎一整圈。

## 决定

- 变量声明新增可选 `wrap: true`：`min` 与 `max` 是同一个位置。取值仍在 `[min, max]` 内。
- 对 `wrap` 变量，`animate` 走较短的一边，必要时从 `max` 跨到 `min`（或反向）；Headless Reducer 照常直接应用终值。
- 录制拖动的宿主把超过半圈的移动拆成每段不到半圈，回放因此沿原方向转。
- 能力 `variables:wrap` 的执行版本为 0.7.0。

## 原因

“同一个位置”是变量本身的性质，不是某个动作的选项；声明在变量上，滑杆、拖点、动画和学生任务读到的是同一个事实。

## 后果

- Core：Schema、校验、Semantic BoardState 保留 `wrap`；执行能力。
- Web Runtime：变量动画沿较短的一边插值。
